# FIM_Monitorizacion_Integridad_Archivos_Bash
He desarrollado un script en Bash que actúa como un sistema de monitorización de integridad (FIM) para WSL/Ubuntu. Vigila un archivo crítico calculando su hash SHA-256 en segundo plano, y si detecto cambios, envío una alerta por SMTPS y actualizo la línea base automáticamente.
